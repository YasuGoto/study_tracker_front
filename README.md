# Study Tracker Frontend

勉強時間を記録・可視化するアプリのフロントエンド。

## 技術スタック
- **Framework**: Next.js（App Router）/ TypeScript
- **Styling**: Tailwind CSS
- **Deploy**: Render

## 機能
- ユーザー認証（登録・ログイン）
- 勉強タイマー（開始・停止）
- 1日の合計勉強時間表示
- 過去1年分の草グラフ表示（GitHub風）

## 画面
- `/login` - ログイン
- `/register` - 新規登録
- `/home` - タイマー・合計時間
- `/history` - 草グラフ履歴
- https://study-tracker-front.onrender.com/
